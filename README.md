# SubGate

SubGate — мониторинг VPN-нод Remnawave и трафика Xray. Он собирает скорости и журналы соединений, проверяет доступность нод и показывает объяснимые наблюдения для разбора владельцем.

Подписки и управление подписчиками обслуживает отдельный `remnawave-subscription-middleware/`. Внешняя DDoS/firewall-защита остаётся скриптам на нодах.

## Возможности

- Синхронизация нод и идентификаторов аккаунтов с Remnawave через API и webhooks.
- Agent: Xray StatsService и access.log, live-скорости, история расхода, источники/назначения соединений и диагностика сбора.
- Разбор аномалий: измерения и пороги, журнал, заметки, решения владельца и аудит.
- Health-пробы, локальный IP/ASN lookup, экспорт и зашифрованные резервные копии.
- Дополнительный Linux worker: nDPI, анализ длительной перегрузки и временный TC/TBF shaper.

Автоматическое ограничение изначально выключено. Оно требует независимых подтверждений, выделенного сетевого пути аккаунта и настроенной политики. Большой расход или P2P сами по себе не доказывают нарушение. [Условия и подключение worker](docs/NODE_MONITORING.md).

## Установка

На центральном Linux-сервере нужны Git, Docker Engine, Docker Compose v2 с `--wait` и curl. Создайте DNS для домена SubGate и откройте TCP 80/443:

```bash
git clone https://github.com/Mrzalupa-lolz/subgate.git
cd subgate
sudo bash deploy/install-core.sh
```

Установщик спросит домен, URL Remnawave и API-токен, создаст пароль владельца, запустит Core с Caddy/HTTPS и проверит доступность. Если HTTPS уже обслуживает Nginx/Caddy, используйте `--proxy external` после настройки прокси.

Затем в консоли откройте **«Агенты → Подключить агент»**, выберите ноду и выполните выданную команду на ней. На ноде должны работать Xray StatsService и access.log. Агент подключается к Core исходящими запросами и не получает токен панели.

[Полная инструкция](docs/DEPLOYMENT.md): установка, существующий HTTPS-прокси, диагностика, обновление и восстановление.

## Демонстрация

Без подключения Remnawave:

```bash
docker compose -f deploy/compose.demo.yaml up --build -d
```

Откройте `http://127.0.0.1:8080`: логин `admin`, пароль `subgate-demo`. Используются синтетические данные и отдельный volume.
