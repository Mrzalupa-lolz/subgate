# Правила реестра

### Нумерованный реестр исходных формулировок

289 строк перенесённых требований/принципов/контекстных ограничений и reference capabilities. Формулировки сохраняются на языке источника, чтобы не потерять условия. Reference/non-goal/context строки **не являются добавленными функциями** и не планируются автоматически. Каждый ID связан с исходным файлом и номером строки. Заголовки, примеры/диаграммы и библиография сами по себе не отдельные функции; их условия включены в соответствующие строки и source ссылки.



Строки сгруппированы по областям; исходные заголовки сохранены в файлах областей. INDEX содержит только ID, область и статус. Адреса ссылок адаптированы к каталогу registry; остальные поля не изменены.
