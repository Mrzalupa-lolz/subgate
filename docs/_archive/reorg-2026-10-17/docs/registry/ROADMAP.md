## 5. Roadmap небольшими этапами

**Будущая работа, не выполнялась в этом аудите.** Каждый проход — 1–2 часа и один проверяемый результат. Если задача не помещается, завершить только обозначенную узкую часть, оставить функцию PARTIAL и разбить следующий проход. Ветви после scope-вопросов не начинать до ответа. Все новые Test* ниже — **планируемые**, их ещё нет, они не являются доказательствами реестра.

Для критериев с новым тестом использовать `require_test PACKAGE NAME`: helper из [OPERATIONS.md](OPERATIONS.md) требует наличие и PASS указанного теста, поэтому «no tests to run» не считается успехом. После него — `make check` на Linux. Тесты выполнять на synthetic/test fixtures, а не чужих секретах, production logs/DB или живых destructive actions.
