# Архив контура подписок

По решению владельца 2026-11-01 SubGate занимается мониторингом Remnawave/Xray. Gateway, transforms, tier selection, requestmonitor и специализированные тесты перенесены сюда с расширением `.disabled`, чтобы Go их не собирал. В архиве также сохранён локальный requestmonitor предыдущей правки, который ещё не был закоммичен.

Маршруты подписок и request-signals возвращают 404. Выдачу подписок обслуживает remnawave-subscription-middleware напрямую, без SubGate в цепочке. Удаление маршрутов означает прекращение совместимости со старыми subscription URL SubGate после перезапуска новой версии; DNS и работающие процессы эта правка не меняет.

Старые таблицы и правила в SQLite не удалены. `legacy_storage_test.go` в активных тестах — только адаптер проверки шифрования старых snapshot-строк и ротации ключей; в рабочий бинарник он не входит.
