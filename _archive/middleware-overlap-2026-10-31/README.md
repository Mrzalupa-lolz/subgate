# Временно отключено: функции, переданные middleware

Дата: 2026-10-31. Назначение: сохранить прежний код SubGate, чтобы можно было вернуть его после разделения функций с `remnawave-subscription-middleware`.

Вынесены из активного кода:

- Инъекции `append`, `prepend`, `patch`, `remove`, полные Xray-профили, обработчики `/api/v1/injections`, UI и связанные тесты/fixture.
- Действия пользователей `enable`, `disable`, `reset-traffic` через `/api/v1/users/{id}/actions/{action}` и кнопки консоли.

В `originals/` лежат исходные файлы с суффиксом `.disabled`. Для общих файлов это полные копии до изменений; для отдельных модулей это перенос из рабочего дерева. Сохранены также документация и прежний inventory. `manifest.json` содержит исходный путь, путь копии, SHA-256 и признак `moved`. Архив исключён из Docker-контекста; Go не собирает каталог `_archive` и файлы `.disabled`.

Старые правила в SQLite сохраняются, но не исполняются. Полные JSON-профили и произвольные JSON-патчи требуют ручного переноса или возврата этого кода: middleware не предоставляет точной замены каждой операции.

Сравнение возможностей и схема подключения: [middleware-integration](../../docs/middleware-integration.md).

## Как вернуть

Сначала просмотрите изменения: восстановление общих файлов возвращает их целиком, включая прежние routes/UI/тесты/документацию. Не копируйте только модули routing: для их использования нужны обработчики и точки вызова из тех же снимков.

Из корня репозитория:

```powershell
python _archive/middleware-overlap-2026-10-31/restore.py
python _archive/middleware-overlap-2026-10-31/restore.py --apply
```

Первый вызов только проверяет контрольные суммы и показывает список. Второй восстанавливает исходники, если текущие файлы соответствуют состоянию после переноса. При последующих изменениях файлов скрипт остановится, чтобы их не перезаписать: сравните нужные `.disabled` и перенесите изменения вручную. Новые документы/проверки этой реорганизации остаются на месте; после полного возврата уберите или скорректируйте `core/internal/server/middleware_overlap_test.go`, который проверяет отключение функций.

Архив при восстановлении сохраняется. Перенос правил в PHP, перезапуск служб и развёртывание выполняются отдельно.

- `go build ./core/cmd ./agent/cmd`.
- `go test ./core/internal/routing ./core/internal/gateway ./core/internal/panel`.
- `go test ./core/internal/server -run 'Test(MiddlewareOwned|LegacyInjections|AuthenticationCSRF|Quota|Policy|Subscription|Gateway|Routing|Pin|Tier)' -count=1`.

Также прошли `node --check web/app.js`, `git diff --check`, проверка SHA-256 всех 29 архивных копий и предварительная проверка `restore.py` без записи. Каждому из шести перенесённых файлов соответствует копия в архиве. Полный набор тестов и совместная работа с живым PHP middleware в этой проверке не запускались.
